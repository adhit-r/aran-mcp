# Aran MCP Sentinel Website

This is the official website for Aran MCP Sentinel, built with Astro and deployed to GitHub Pages.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

The website is automatically deployed to GitHub Pages when changes are pushed to the `main` branch. The deployment workflow is configured in `.github/workflows/deploy-website.yml`.

## Design

The website uses a neo-brutalist design system with:
- Bold typography
- High contrast colors
- Sharp borders and shadows
- Minimal, clean UI

## Pages

- `/` - Home page
- `/features` - Features overview
- `/docs` - Documentation links
- `/blog` - Blog listing
- `/contact` - Contact information

## SEO

The website includes:
- Meta tags and Open Graph tags
- Structured data (JSON-LD)
- Sitemap generation
- robots.txt
- Semantic HTML
